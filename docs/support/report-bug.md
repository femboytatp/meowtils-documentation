# **Report Bug**

!!! Note

    This requires you to register a [GitHub account](https://github.com/signup), alternatively you can join [Mega's Discord Server](https://discord.gg/XVrHPaMGGv) for support.

---

## Try this before reporting a bug:

- Remove all your mods except for **Meowtils**.

    !!! Info "Mod Conflicts"

        In some cases issues appear due to a mod conflict, if so you should still report this as a bug so we can investigate, as can sometimes fix this conflict on our end. 
        
        **Make sure to specify that its due to a conflict and what mod was causing it in your bug report.**

- Temporarily remove all **Extensions**.

    !!! Info "Extensions"

        **Extensions** can cause issues or crashes, you should remove them to make sure they are not the reason. If an extension is at fault, you should contact the author of that extension instead.

- Verify Hypixel language is set to `English`.

    !!! Info "Language"

        Many features depend on scoreboard or chat text, make sure your **Hypixel** language is set to `English`.

- Try a new instance of Minecraft.

    !!! Info "New Instance"

        Sometimes a fresh instance can solve issues with launching.

        **How to create a fresh instance:**

        1. Create a new folder called .minecraft2

        2. In your launcher, add .minecraft2 as the path instead of the default .minecraft

        3. Launch your game once to download any necessary files

        4. Now launch with your mods, including **Meowtils**

- Use the [official Minecraft launcher](https://www.minecraft.net/download).

    !!! Info "Different Launcher"

        While most launchers that support Forge should generally work, some may not. Alternatively you could try using a different launcher from the one you are currently experiencing an issue with.

- Reinstall Java.

    !!! Info "Java"

        If you have issues with **crashing** try to re-install java.

        **Steps:**

        1. Uninstall java.

        2. Restart computer (optional but recommended).

        3. Reinstall java.

        4. Restart computer again (optional but recommended).

        5. Attempt to launch again.

## Reporting a bug:

While making a bug report try to be as specific as possible.

Report them [**HERE**](https://github.com/femboytatp/meowtils/discussions/categories/bugs).
