# **Settings**

#### General settings.

---

## Mod

General settings that are related to the **Meowtils** mod.

### Auto-Updates

If enabled, new updates will automatically be installed. This is opt-out and if disabled it will only provide a link to the update page for you to manually install it.

More about **Auto-Updater** [**HERE**](../../other/auto-updates.md).

### Smooth font

Use smooth font for HUD elements and modules that render text in your world. If disabled the normal Minecraft font will be used instead.

!!! Info

    The GUI will always use smooth font regardless of this.

### Copy chat

Lets you copy chat messages by hovering over them and right clicking.

!!! Bug "Important"

    Certain chat mods as well as Lunar Client may break this, which in that case you should use the copy chat feature provided by those mods instead.

## Prefix

Settings to customize the prefix shown in chat messages.

**Modes:** _Default, Myau, Fire, Nebula, Air, Custom, Short_

Lets you customize the prefix for chat messages.

!!! Tip
    
    Use the `/theme` command to pick colors for Custom & Short themes.

### Lowercase

Will make all prefix letters lowercase.

## Preview

Sends a message in chat to preview currently selected prefix theme.

## API

Different API keys that may be required for some features to work.

### Hypixel Key

!!! info "Hypixel API"

    In order to use the Hypixel API you need a key.

    **How to obtain an API key:**

    1. Go to [Hypixel Developer Dashboard](https://developer.hypixel.net/).

    2. Sign in with your Hypixel forums account.

    3. Click `CREATE API KEY`

    4. In-game, add your key with `/meowapi <key>`

    _Normal keys don't last forever and will have to be regenerated. You may also need a forums account that is older than a day._

### Coral Key

!!! Info "Coral API"

    In order to use Urchin you need a Coral API key.

    **How to obtain an API key:**

    1. Join [Urchin Discord](https://discord.gg/urchin)

    2. Verify with your username, this assumes you have linked your discord to your username on Hypixel.

    3. Run /info then /dashboard to generate your API key with their **coral discord bot**.
