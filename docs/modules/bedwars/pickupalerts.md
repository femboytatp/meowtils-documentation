# **PickupAlerts**

#### Alerts you when someone picks up a resource.

!!! Info

    This is limited by server render distance for entities, by default this is `64 blocks`, however it may be more or less which depends on the server.

---

## Ping sound

Plays a sound when a player picks up a resource.

## For Iron Ingots

Will alert if a player picks up iron ingots.

## For Gold Ingots

Will alert if a player picks up gold ingots.

## For Diamonds

Will alert if a player picks up diamonds.

## For Emeralds

Will alert if a player picks up emeralds.
