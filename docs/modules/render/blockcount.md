# **BlockCount**

#### Displays currently held block count and alerts when running low on blocks.

---

## Text color

Changes color of the HUD text.

## Scale

Changes text size.

## Alert threshold

Alerts you when you only have this many blocks left if alert when low is enabled.

## Ping sound

Plays a sound for alerts.

## Alert when low

Toggle alerting if low on blocks.

## Show suffix

Will show ``Blocks`` text as a suffix after the currently displayed count.

## Fade out

When enabled this will only make the text appear if your block counts recently changed, if it did not change the text will fade out and won't be displayed until it changes once again.
